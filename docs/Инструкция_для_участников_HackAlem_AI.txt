Инструкция для участников HackAlem AI
1. Активируйте доступ к Codex, API OpenAI и NVIDIA. Инструкция находится в
   файле «Активация OpenAI и NVIDIA для участников HackAlem AI». Не
   публикуйте API-ключи в GitHub.

2. Выберите один кейс. Решать все кейсы трека не требуется.

3. Ознакомьтесь с требованиями кейса и критериями оценивания.

4. Обсудите реализацию с командой, распределите роли и задачи.

5. Выберите способ работы:
     ○   Через приложение Codex: подключите свой GitHub аккаунт к Codex,
         предоставьте доступ к рабочей папке (репозиторий команды, созданный
         платформой), ставьте задачи через промпты.
     ○   Через Visual Studio Code: установите расширение Codex, войдите в
         аккаунт, откройте репозиторий команды, разработайте решение и отправьте
         код в GitHub.
     ○   Можно использовать любой другой способ разработки. Главное —
         использовать AI-агента и разместить итоговый код в GitHub-
         репозитории команды, выданном платформой хакатона.

6. За 5 часов реализуйте обязательные требования кейса и проверьте основной
   сценарий от входных данных до результата.

7. Оформите README. Укажите:
     ○   что делает проект;
     ○   что реализовано;
     ○   используемые технологии и архитектуру;
     ○   порядок установки и запуска;
     ○   пример проверки;
     ○   используемые данные и внешние сервисы;
     ○   известные ограничения;
     ○   ссылку на развёрнутую версию, если она есть.

8. Для подготовки README можно использовать промпт организаторов из
   документа кейса, сгенерировать и вставить его через Codex.

9. Отправьте последнюю версию проекта в GitHub-репозиторий команды.
10. Перейдите на страницу треков, выберите свой кейс и нажмите «Сдать
    решение». Заполните название и описание проекта. Решение можно обновлять
    до дедлайна хакатона.


Промпт для README:
Вот промпт, который участники смогут просто вставить в Codex:

«Проанализируй текущий проект и создай для него полноценный README.md на
русском языке.

README должен быть понятен жюри хакатона и содержать:
1. Название проекта
2. Краткое описание — какую проблему решает проект и для кого.
3. Что реализовано — основные функции и возможности решения.
4. Как работает решение — кратко опиши основной пользовательский сценарий от
входных данных до результата.
5. Технологии — языки, фреймворки, библиотеки, AI-модели, API и внешние
сервисы.
6. Архитектура проекта — основные компоненты и как они взаимодействуют.
7. Установка и запуск — пошаговая инструкция с необходимыми командами.
8. Как проверить решение — пример сценария, который может повторить жюри.
9. Данные и интеграции — какие источники данных, API или внешние сервисы
используются.
10. Ограничения — что не реализовано или какие ограничения есть у текущей
версии.
11. Ссылка на deployed-версию, если она существует.

Используй только информацию, которую можно подтвердить по текущему
репозиторию. Не придумывай функции, технологии или результаты, которых в
проекте нет. Оформи README аккуратно в Markdown.»
