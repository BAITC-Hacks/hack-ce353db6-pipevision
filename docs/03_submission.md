## Название проекта
WindAgent — Agentic AI для почасового прогноза выработки ВЭС на 24–48 часов

## Описание проекта
Автономный агент, который каждый день сам проходит полный цикл прогноза выработки ВЭС: получает по координатам турбин архивные прогнозы погоды Open-Meteo, выпущенные именно в день прогноза (best_match + ансамбль GFS/ICON/ECMWF, лаг 1 и 2 суток), готовит признаки, прогоняет обученную на истории 2024–2026 модель градиентного бустинга и выдаёт почасовой прогноз мощности на 48 часов по каждой турбине и парку с интервалом P10–P90. Затем проверяет результат (диапазоны, рампы, ревизия к вчерашнему выпуску, климатология, окна штиля для ТО), при необходимости пересчитывает и пишет отчёт диспетчеру на русском. Цикл ведёт LLM (OpenAI gpt-5-mini, tool calling) с валидацией ответов и проверкой чисел; без ключа те же шаги выполняются по правилам, прогнозные значения не меняются. Тестовый февраль 2026 воспроизведён «как в прошлом»: 28 ежедневных выпусков 31.01–27.02, все через LLM. Честный бэктест дек.2025–янв.2026 по тому же протоколу: MAE 0,175 от номинала против 0,210 у кривой мощности и 0,373 у персистентности. Режим live даёт оперативный прогноз по текущему запуску Open-Meteo. Единый файл сдачи `outputs/submission_feb2026.csv` (турбины 1, 2 и парк, горизонты 24/48 ч, местное время датасета) и команда `wind-agent evaluate --actual …` для сверки с фактом за февраль. Система работает для любой площадки в Казахстане: по координатам агент сам получает прогноз погоды и строит прогноз переносом модели (с честной пометкой), час выпуска настраивается, есть панель оператора (Streamlit). В комплекте: 3D-визуализация прогнозного поля ветра над рельефом с раскладкой парка «Нурлы» из OSM (three.js), анализ влияния направления ветра (разгон с востока ×1,25, след парка с запада), калибровка интервалов, проверка фактов в тексте LLM, воспроизводимость из чистого клона без ключей (uv/pip, Makefile, Docker, 32 офлайн-теста), README по требованиям жюри.
