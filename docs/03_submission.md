## Название проекта
WindAgent — Agentic AI для почасового прогноза выработки ВЭС на 24–48 часов

## Описание проекта
WindAgent получает архивный прогноз погоды Open-Meteo (best_match и GFS/ICON/ECMWF, лаги 1–2 суток), готовит признаки и рассчитывает почасовую мощность двух турбин и парка на 48 часов. Агент проверяет рампы, ревизии и ограничения, формирует отчёт; LLM объясняет результат через tool calling с проверкой чисел, без ключа работают детерминированные правила.

Временной бэктест декабрь 2025–январь 2026: MAE **0,17223** номинала, RMSE **0,23765**, покрытие P10–P90 **75,78 %** против номинальных 80 %. MAE бейзлайнов: кривая мощности 0,21029, персистентность 0,37318. Финальная модель переобучена после исправления погодного контекста с сохранением калибровки. Это исправление корректности входа, а не доказанное улучшение точности; надёжность для ежедневного планирования требует дальнейшей проверки. [Протокол и эксперименты](research/forecast_improvement.md).

Февральский архивный replay (28 выпусков с LLM), отчёты и `outputs/submission_feb2026.csv` сохранены от предыдущей модели и не пересоздавались с новым артефактом. Для собственных прогнозов файл сдачи собирается после нового полного replay. Февральского факта в исходном датасете нет; его можно проверить через `wind-agent evaluate --actual …`.

Обновление панели в этом PR: три KPI, график и компактная схема расчёта; подробности, чат и журнал открываются по запросу. Выпуск и горизонт 24/48 ч едины для показателей и пояснений. Короткая анимация появляется только по действию пользователя, без постоянных видеовставок. Отдельное пространство исследования площадки содержит атлас ветра Казахстана (1199 ячеек), оценку ресурса ERA5, КИУМ, рельеф и 3D. Прогноз других площадок — перенос модели «Нурлы» с явным ограничением.

В комплекте: CLI, режим live, калибровка интервалов, проверка чисел LLM, офлайн-тесты, uv/pip, Makefile и Docker.
