## Название проекта
WindAgent — Agentic AI для почасового прогноза выработки ВЭС на 24–48 часов

## Описание проекта
Автономный агент, который каждый день сам проходит полный цикл прогноза выработки ветроэлектростанции: получает по координатам турбин архивные прогнозы погоды Open-Meteo, выпущенные именно в день прогноза (ансамбль GFS/ICON/ECMWF + best_match, лаг 1 и 2 суток), готовит признаки, прогоняет обученную на истории 2024–2026 модель градиентного бустинга и выдаёт почасовой прогноз мощности на 48 часов по каждой турбине и по парку с интервалом P10–P90. Затем агент проверяет результат (диапазоны, рампы, ревизия относительно вчерашнего прогноза, климатология), решает о пересчёте и пишет отчёт на русском; LLM (OpenAI) ведёт цикл через tool calling, без ключа система работает детерминированно. Тестовый февраль 2026 воспроизведён «как в прошлом» — 28 ежедневных выпусков с 31.01 по 27.02. Честный бэктест на декабре 2025 – январе 2026: MAE 0.175 от номинала против 0.373 у персистентности. Режим live даёт оперативный прогноз по текущему прогнозу погоды. В комплекте 3D-визуализация поля ветра над рельефом площадки, воспроизводимость из чистого клона (uv/pip, Docker, тесты).
