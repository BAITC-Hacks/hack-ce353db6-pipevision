## Пакет R1 — Рельеф и направленная поправка ветра (ценность + оригинальность)

Наблюдение: замер ветра на турбинах в ~1,2 раза выше прогноза Open-Meteo на 100 м (сетка 11 км не видит ускорение потока в Шелекском коридоре), корреляция по направлению не изучена.
Задача:
1. По истории (`data/cache/openmeteo/prevruns__t1__2024-02-16__2026-01-31.csv`, факт — `wind_agent.data.load_hourly`) посчитать коэффициент `замер/прогноз` по 16 секторам направления и по диапазонам скорости; оценить стабильность по сезонам.
2. По сетке высот `data/terrain/dem_grid.csv` (появится после `scripts/fetch_dem.py`, ±6 км, шаг 250 м) построить простую terrain-aware поправку: экспозиция/уклон площадки относительно направления ветра, либо прогон WindNinja (если ставится за 15 минут), либо мass-consistent приближение. Цель — признак `terrain_speedup(direction)` для модели.
3. Добавить признаки в `src/wind_agent/features.py` (с fallback, если данных нет) и показать прирост на бэктесте. Отчёт с картинками — `docs/research/R1_terrain.md`.
