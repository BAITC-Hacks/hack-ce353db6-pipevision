## Пакет R1 — Рельеф и направленная поправка ветра (ценность + оригинальность)

Наблюдение (посчитано 23.09 14:10, см. docs/01_analysis.md, раздел 8): ветер бимодальный — ВСВ/В 44 % часов, ЗЮЗ/З 42 %. При ветре с ВСВ/В замер на турбинах в **1,23–1,26 раза** выше прогноза Open-Meteo на 100 м, а при ветре с ЗЮЗ/З — **0,91–0,98**. При одинаковом прогнозе 7–9 м/с средняя мощность с востока 0,67–0,73, с запада 0,45–0,51. Контекст по спутнику: наши две турбины стоят на юго-восточном краю ВЭС «Нурлы» (в парке больше десятка турбин), к западу — посёлок Нурлы, к северо-востоку — большой лесной массив. Гипотеза: с востока — разгон потока в Шелекском коридоре, с запада — след (wake) остальных турбин парка плюс шероховатость посёлка. Модель уже учитывает направление (dir_sin/dir_cos), смещение по секторам на тесте ±0,06, но явные признаки могут снять остаток.
Задача:
1. Уточнить коэффициент `замер/прогноз` по 16 секторам и диапазонам скорости (данные: `wind_agent.data.training_frame`), проверить стабильность по сезонам и годам; отдельно — зависимость от скорости (wake сильнее при 6–10 м/с, при номинале исчезает).
2. Взять раскладку парка из OpenStreetMap (Overpass API: `node["power"="generator"]["generator:source"="wind"]` вокруг 43.645, 78.536, радиус 5 км) и полигоны леса/посёлка (`landuse=forest|residential`, `natural=wood`). Построить для каждого сектора направления признаки: число турбин парка с наветренной стороны в конусе ±15° на расстоянии до 2 км (прокси wake, модель Jensen — если успеете), доля леса/застройки в наветренном секторе на 1–3 км (шероховатость), а по сетке высот `data/terrain/dem_grid.csv` (±6 км, шаг 250 м) — уклон/экспозицию площадки относительно ветра (разгон). WindNinja — только если ставится за 15 минут.
3. Добавить признаки в `src/wind_agent/features.py` (с fallback на нули, если данных нет) и показать прирост на бэктесте по секторам. Отчёт с картинками — `docs/research/R1_terrain.md`.
